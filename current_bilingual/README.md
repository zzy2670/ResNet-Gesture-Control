# ResNet 项目：当前正式文档与双语图源

本目录配套原 ResNet 十二模型完整项目，更新当前正式文档及配图。训练数据、模型权重和冻结测试结果沿用完整项目，不因文档更新而重新训练或更换测试分组。历史 Word 原稿保留。

## 阅读顺序

1. [交接说明 v3](documents/交接说明_v3_中英文配图.docx)：先了解当前 GitHub 入口、交接内容和组员后续工作；v2 保留为历史原稿。
2. [项目方案 v13](documents/基于ResNet18的手势识别项目方案_v13_中英文配图.docx)：了解任务、数据、模型及实验流程。
3. [综合实验报告 v4](documents/A与B协议ResNet训练与对比实验报告_v4_中英文配图.docx)：查看 A/B、合并/不合并及三种 ResNet 的实测结果。

正式文档的每处配图同时提供中文和英文版本，直接放在正文对应位置。原始手势照片保留像素，通过成对的图注说明语言版本。英文版与中文版使用同一批实验数据。

## 文件夹说明

| 路径 | 内容 |
| --- | --- |
| `documents/` | 当前交接 v3、方案 v13、报告 v4，以及保留的交接 v2 历史原稿 |
| `assets_diagrams/` | 项目流程、网络结构等示意图，含中英文 PNG、可编辑 VSDX、原始图源和生成脚本 |
| `assets_results/` | 实验曲线、混淆矩阵、Grad-CAM 和检测示例，含中英文 PNG/SVG、冻结数据与生成脚本 |
| `assets_reference/` | 手势照片、参考图及预训练示意图，含中英文图、可编辑改绘图源和来源记录 |
| `analysis/` | 整图命令准确率变化的逐样本复算，使用已保存预测，不重新运行模型 |
| `embedded_originals/` | 旧正式文档的原始嵌入图，用于对照 |
| `docx_qa/` | 文档排版与图像检查所用中间文件 |
| `reviews/` | 各图源分支及三份文档的独立审查记录 |

每组图的 `manifest.json` 记录图号、语言文件、图注及来源。参考论文的改绘 SVG 是本项目可编辑改绘，不代表取得论文作者的原始制图工程。Grad-CAM 来自冻结实验输出；示意图和真实模型输出在图注中区分。

## 重绘与校验

各图源目录的 README 和生成脚本给出重绘方法。结果图使用随包的冻结数据；重绘无需训练模型。`build_bilingual_documents.py` 负责把已审配图装入文档；修改图源后需要重新检查生成图及文档排版。

`PACKAGE_MANIFEST.json` 记录原双语 ZIP 封包时的文件、长度与 SHA-256，供核对原包；当前仓库的新增交接 v3 和入口修订不由该历史清单覆盖。`package_bilingual_bundle.py` 是原封包脚本，执行后会在脚本所在目录生成 `PACKAGE_RECEIPT.json`，记录最终 ZIP 的长度与 SHA-256，且不把收据放入自身描述的 ZIP。当前 GitHub 目录未包含这份收据；脚本仍绑定原交接 v2 及原独审结果，不能作为当前仓库的一键重打包入口。
