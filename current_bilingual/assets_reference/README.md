# 参考图、手势照片与预训练示例的双语图源

本目录包含13组参考图的中文与英文 PNG、SVG、图注、原图及来源材料。`manifest.json` 中全部文件路径均相对于本目录；解压后保留目录结构即可使用。

## 重排方法

使用 Python 3 与 Pillow。在本目录打开终端，运行：

```powershell
python -m pip install Pillow
python generate_reference_bilingual.py
```

脚本通过自身所在位置查找文件，因此也可以从其他工作目录传入脚本的完整路径运行。脚本覆盖本目录同名的双语输出和 `manifest.json`，保留 `originals/` 和 `source_evidence/` 的来源文件。

字体使用 Windows 的 `C:/Windows/Fonts/msyh.ttc` 与 `msyhbd.ttc`（微软雅黑及粗体）。非 Windows 环境需要先提供可用的中文字体，并修改脚本开头的 `FONT` 与 `BOLD`；更换字体后应重新检查文字宽度与裁边。查看 SVG 的软件也需要安装相应字体。

## 输入与编辑范围

- `originals/` 保存原始嵌入图。`reference_inputs.json` 提供图号、原图相对路径、原图SHA与英文图注；生成器中的中文图注常量修复旧清单的编码损坏。
- `source_evidence/` 保存已存在的元数据、历史图源与历史脚本。重排只读取固定原图及 `v9_cam_matrix_metadata.json` 中的目标标签，不运行这些历史模型脚本。
- 九张无内部文字的手势照片使用相同像素的中英文文件，语言由图注表达；对应 SVG 是原照片的嵌入容器。
- 电缆参考图的英文 PNG 保留原始文件字节；中文 SVG 为可编辑文字翻译层。其英文 SVG 保留原始栅格，未取得原作者可编辑文字工程。
- 手图 Grad-CAM 示例的双语 SVG 具有可编辑文字层；照片、热图与色尺继续使用已保存的原始栅格证据。历史 VSDX 作为来源保留，不代表最终双语改编版本。

本流程不读取训练数据、不重新运行模型，也不改变热图或照片的科学像素。预训练 ImageNet 示例的目标及用途限制保留在图内和图注中。

## 校验

生成器先校验原图SHA，再逐块比较54处科学证据区域的原始像素与输出像素；九张照片的中英文 PNG 文件SHA还必须等于原文件。`manifest.json` 记录每张图的输出SHA、依赖、可编辑范围和像素核对结果。重新排版后仍应打开中英文 PNG 与 SVG 检查标签语言、文字溢出与最终文档可读性。
